## ✨ Features (Update Powerfull)

- **Class-Based Structure**: Code yang lebih rapi dan modular.
- **Colorful Interface**: Tampilan CLI dengan warna (ANSI support).
- **User-Agent Rotation**: Menggunakan berbagai User-Agent modern untuk stealth.
- **Status Indicators**: Ikon status `[✓]`, `[x]`, `[!]` untuk feedback yang jelas.

## 🛠️ Requirements

- PHP 7.4 atau lebih baru (CLI)
- cURL Extention enabled

## 🚀 Installation & Usage

1.  **Clone Repo**

    ```bash
    git clone https://github.com/username/SMS-BOMBER-JDID.git
    cd SMS-BOMBER-JDID
    ```

2.  **Run Script**

    ```bash
    php jdid.php
    ```

3.  **Input Data**
    - Masukkan Nomor HP (Format: 8xxxxxxxx)
    - Masukkan Jumlah Spam
    - Masukkan Jeda Waktu (Delay)
